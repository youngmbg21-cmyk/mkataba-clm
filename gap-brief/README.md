This branch (gaps/brief) holds only the brief. It is never merged into main.

- SPEC.md — the brief every helper works from. Where it names local folders, read them here instead:
  - "Folder D" (the drawings, D/r<N>.html) → gap-brief/designs/r<N>.html
  - "Folder G" (G/r<N>.txt and G/r<N>-a.png) → gap-brief/extracts/
  - prior files → gap-brief/prior.json, prior2.json, prior3.json (earlier passes' reports, per lane)
  - "/home/user/wt/<LANE>" → your own checkout of branch gaps/<LANE>
  - photos ("/home/user/wt-shots/<LANE>/") → a folder in your scratchpad; never commit them
